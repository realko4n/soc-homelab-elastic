# 03. Симуляция атак и расследование инцидентов (Red vs Blue Team)

В этом разделе собраны практические сценарии атак, проведенные с атакующего узла **Kali Linux (`192.168.1.208`)** на целевую рабочую станцию **Windows 10 Pro (`192.168.1.207`)**, с последующим поиском артефактов в **Elastic SIEM (Kibana)** и разработкой рекомендаций по защите.

## 📋 Каталог кейсов (MITRE ATT&CK)

| № | Название сценария | Тактика (MITRE) | Техника (ID) | Источники телеметрии | Статус |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **01** | [Подбор паролей по протоколу SMB (Brute Force)](./01-smb-brute-force.md) | Credential Access | [T1110.001](https://attack.mitre.org/techniques/T1110/001/)]) | Windows Security (`4625`, `4740`) | ✅ Завершено |
| **02** | *Скрытое выполнение PowerShell-скрипта (Fileless Execution)* | Execution | [T1059.001](https://mitre.org) | Sysmon (`1`, `3`, `22`), PowerShell (`4104`) | 🔄 В планах |
| **03** | *Закрепление в системе через реестр (Registry Run Keys)* | Persistence | [T1547.001](https://mitre.org) | Sysmon (`1`, `12`, `13`) | 🔄 В планах |

## 🔍 Методология разбора каждого инцидента
Каждый врайтап структурирован по стандарту реагирования на инциденты (IR):
1. **Контекст и MITRE ATT&CK:** описание вектора атаки, тактики и техники.
2. **Симуляция (Red Team):** воспроизведение атаки и вывод инструментов атакующего.
3. **Детект и анализ (Blue Team):** KQL-запросы в Kibana, разбор полей событий и скриншоты доказательств.
4. **Рекомендации (Remediation):** меры по сдерживанию атаки, настройке политик ОС и созданию правил корреляции SIEM.
